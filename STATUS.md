# List of Badges That We Apply For

- **Evaluated - Functional**: We provide all code, data, and evaluation results for all experiments described in the paper. The artifact is well-documented and can be used to run the same evaluation on your own machine and to reproduce the results from the log files. The evaluation results are reproducible.
- **Evaluated - Reusable**: The code is easily reusable for reproducing the experiments, but also for running new experiments, or for adapting the code to new use cases. We provide a Dev Container configuration for easy development and reuse using VS Code, in addition to the pre-built Docker image.
We provide utility scripts and documentation for running your own experiments on new benchmarks and with changed configurations.
- **Available**: The artifact with all data is publicly and permanently available on Zenodo with a DOI.
